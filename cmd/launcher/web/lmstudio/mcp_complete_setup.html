0 Wymagania Wstępne

🔍 Sprawdź przed rozpoczęciem:
  • Windows 10/11 (64-bit)
  • LM Studio 0.3.17 lub nowsze
  • Node.js LTS tylko dla lokalnych serwerów korzystających z node lub npx
  • Opcjonalnie: Git (do klonowania repozytoriów)

Node.js dla lokalnych serwerów MCP

  1. Pobierz Node.js LTS ze strony: nodejs.org
  2. Zainstaluj z domyślnymi opcjami
  3. Sprawdź instalację: node -v i npm -v

1 Szybki Start w LM Studio

✅ Najprostsza metoda Zdalny serwer MCP nie wymaga kopiowania paczek ani tworzenia folderu C:\Programy\MCP.

Krok po kroku:

  1. Uruchom LM Studio i otwórz zakładkę Program

    Znajdziesz ją w prawym panelu aplikacji.

  2. Wybierz Install → Edit mcp.json

    LM Studio otworzy własny edytor konfiguracji. Po zapisaniu pliku automatycznie przeładuje serwery.

  3. Dodaj wybrany serwer

    Możesz wkleić wpis do mcp.json albo użyć przycisku „Add to LM Studio”, jeżeli autor integracji go udostępnia.

  4. Otwórz czat i wybierz narzędzia MCP

    ✅ Dostępne narzędzia pojawią się przy modelu. Lokalne serwery oparte na npx wymagają działającego Node.js w zmiennej PATH.

Oficjalna instrukcja MCP Przyciski „Add to LM Studio”

2 Instalacja Manualna (Git lub ZIP)

ℹ️ Sekcja zaawansowana Te kroki są potrzebne tylko dla lokalnych serwerów uruchamianych poleceniem. Integracje zdalne zwykle wymagają jedynie adresu URL.

Wariant A - Przez Git (polecany dla deweloperów)

cd C:\Programy\MCP
git clone https://github.com/mrkrsl/web-search-mcp.git web-search-mcp-main
cd web-search-mcp-main
npm install
npm run build

Wariant B - Pobieranie ZIP

  1. Wejdź na stronę repozytorium na GitHubie
  2. Kliknij Code → Download ZIP
  3. Wypakuj do C:\Programy\MCP\nazwa-serwera\
  4. Otwórz PowerShell w folderze i wykonaj: 
    npm install
npm run build
📝 Uwaga dla serwerów Playwright: Dla web-search-mcp dodatkowo wykonaj: npm run playwright:install

4 Konfiguracja mcp.json

📍 Lokalizacja pliku:
  • LM Studio przechowuje mcp.json w katalogu ustawień
  • Zwykle: %APPDATA%\LMStudio\mcp.json
  • Możesz też edytować przez interfejs LM Studio

Kompletna konfiguracja (mcp.json):

{
  "mcpServers": {
    "websearch_links": {
      "command": "node",
      "args": [
        "C:/Programy/MCP/web-search-mcp-main/dist/index.js"
      ],
      "env": {
        "SEARCH_PROVIDER": "duckduckgo",
        "WEBSEARCH_MAX_RESULTS": "10",
        "WEBSEARCH_FETCH_CONTENT": "false",
        "WEBSEARCH_FOLLOW_LINKS": "0",
        "WEBSEARCH_SUMMARIZE": "false",
        "WEBSEARCH_TIMEOUT_MS": "8000",
        "WEBSEARCH_LOCALE": "pl-PL"
      }
    },
    "websearch_deep": {
      "command": "node",
      "args": [
        "C:/Programy/MCP/web-search-mcp-main/dist/index.js"
      ],
      "env": {
        "SEARCH_PROVIDER": "duckduckgo",
        "WEBSEARCH_MAX_RESULTS": "10",
        "WEBSEARCH_FETCH_CONTENT": "true",
        "WEBSEARCH_FOLLOW_LINKS": "1",
        "WEBSEARCH_SUMMARIZE": "true",
        "WEBSEARCH_TIMEOUT_MS": "15000",
        "WEBSEARCH_LOCALE": "pl-PL"
      }
    },
    "filesystem": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-filesystem",
        "C:/Programy/MCP/workspace"
      ]
    },
    "memory": {
      "command": "cmd",
      "args": [
        "/c",
        "node",
        "C:/Programy/MCP/memory/node_modules/@modelcontextprotocol/server-memory/dist/index.js"
      ],
      "env": {
        "MEMORY_FILE_PATH": "C:/Programy/MCP/memory/memory.json"
      }
    },
    "sequential_thinking": {
      "command": "cmd",
      "args": [
        "/c",
        "node",
        "C:/Programy/MCP/sequentialthinking/node_modules/@modelcontextprotocol/server-sequential-thinking/dist/index.js"
      ]
    },
    "time": {
      "command": "cmd",
      "args": [
        "/c",
        "node",
        "C:/Programy/MCP/time/node_modules/time-mcp/dist/index.js"
      ]
    },
    "docs_mcp": {
      "command": "npx",
      "args": [
        "-y",
        "@arabold/docs-mcp-server@latest"
      ],
      "env": {
        "DOCS_MCP_STORE_PATH": "C:/Programy/MCP/docs-mcp-data",
        "DOCS_MCP_TELEMETRY": "false"
      }
    },
    "shell": {
      "command": "cmd",
      "args": [
        "/c",
        "node",
        "C:/Programy/MCP/mcp-shell-server/dist/index.js"
      ]
    }
  }
}
⚠️ Ważne uwagi:
  • W JSON zawsze używaj ukośników / zamiast \
  • Upewnij się, że ścieżki do plików dist/index.js są poprawne
  • Jeśli manualna instalacja - dodaj "workingDirectory" dla każdego serwera

5 Test i Weryfikacja

Sprawdzanie działania:

  1. Uruchom LM Studio i rozpocznij nowy czat
  2. Zapytaj o dostępne narzędzia: 
    Jakie masz dostępne narzędzia MCP?

    Powinieneś zobaczyć listę wszystkich zainstalowanych serwerów

  3. Test Web Search (linki): 
    Użyj websearch_links do wyszukania "Audi A3 opinie" i pokaż 5 najlepszych wyników z linkami
  4. Test Web Search (deep): 
    Użyj websearch_deep do szczegółowego zbadania pierwszego wyniku - pobierz treść i streść w 5 punktach
  5. Test Memory: 
    Zapisz w pamięci: "Mój ulubiony kolor to niebieski". Potem zapytaj: "Jaki jest mój ulubiony kolor?"
  6. Test Filesystem: 
    Utwórz plik test.txt w workspace i zapisz w nim "Hello MCP!"
  7. Test Time: 
    Jaka jest aktualna data i godzina?
✅ Jeśli wszystko działa: Gratulacje! Masz w pełni funkcjonalne środowisko MCP. Możesz teraz używać zaawansowanych funkcji AI!

6 Rozwiązywanie Problemów

❌ "Connection closed" / Serwer się nie uruchamia

  • Sprawdź czy plik dist/index.js istnieje w folderze serwera
  • Dla serwerów budowanych: wykonaj npm run build
  • Sprawdź ścieżki w mcp.json - muszą być dokładne
  • Upewnij się że Node.js jest zainstalowany: node -v

🔍 Brak wyników w Web Search

  • Sprawdź połączenie internetowe
  • Zwiększ WEBSEARCH_TIMEOUT_MS do 20000 lub więcej
  • Zwiększ WEBSEARCH_MAX_RESULTS
  • Sprawdź czy WEBSEARCH_LOCALE jest ustawione na "pl-PL"

🌐 Chcę polskich wyników

  • Ustaw "WEBSEARCH_LOCALE": "pl-PL" w konfiguracji
  • W promptach dodawaj "po polsku" lub "w języku polskim"

🚀 Chcę lepszych wyników wyszukiwania

Rozważ użycie płatnych API dla lepszej jakości:

Brave Search API:

"env": {
  "SEARCH_PROVIDER": "brave",
  "BRAVE_API_KEY": "TWÓJ_KLUCZ_API",
  ...
}

Google (przez SerpAPI):

"env": {
  "SEARCH_PROVIDER": "serpapi",
  "SERPAPI_API_KEY": "TWÓJ_KLUCZ_API",
  ...
}

💾 Memory nie zapisuje danych

  • Sprawdź czy folder C:\Programy\MCP\memory\ istnieje
  • Sprawdź uprawnienia do zapisu w tym folderze
  • Sprawdź czy ścieżka w MEMORY_FILE_PATH jest poprawna

⚡ Ogólne problemy

  • Restart LM Studio po zmianach w mcp.json
  • Sprawdź logi w konsoli LM Studio (jeśli dostępne)
  • Upewnij się, że wszystkie zależności są zainstalowane: npm install w każdym folderze
  • Sprawdź czy nie ma konfliktów portów (bardzo rzadkie)
💡 Pro tip: Jeśli jakiś serwer nie działa, możesz go tymczasowo usunąć z mcp.json i dodać później - reszta będzie działać normalnie.
